2. Hosting and server logs

This website runs on a privately operated server. When you visit a page, the web server necessarily processes your IP address and User-Agent so that the page can be delivered to you. Access logs (IP address, timestamp, requested page, User-Agent) are kept for a short period for security and troubleshooting, and are then deleted.

The website is delivered through the Cloudflare content delivery network, which acts as a reverse proxy. Cloudflare processes connection data as part of providing that service. See the Cloudflare privacy policy.

Legal basis: Art. 6(1)(f) GDPR — legitimate interest in operating a secure, functioning website.

3. Contact form

If you use the contact form, your name, email address, message and the IP address the message was sent from are stored so that I can read and reply to your enquiry. The message is also sent to me by email. If delivery fails, the stored copy ensures your message is not lost.

Legal basis: Art. 6(1)(b) GDPR (steps taken at your request prior to a possible contract) and Art. 6(1)(f) GDPR (legitimate interest in receiving and answering enquiries).

You may ask me to delete your message at any time; see section 8.

4. Visitor statistics

I record anonymous statistics about how this website is used, so I can see which content is useful. This runs on my own server and no data is sent to any analytics provider.

The following is recorded for each page view:

  • the page requested and the time of the request;
  • the referring website, if you arrived from one;
  • the country, derived from the connection by Cloudflare;
  • coarse technical information: device type (desktop/mobile/tablet), browser family and operating system family;
  • whether the request came from an automated bot or crawler.

No IP addresses are stored for statistics. To count how many different people visited on a given day, the IP address is combined with a secret value and today's date, and immediately reduced to a meaningless pseudonym. That pseudonym changes every day, so it cannot be used to recognise you on a later visit.

No cookies, no device identifiers and no fingerprinting are used for statistics, and no data is shared with third parties. Because the statistics cannot be linked to you, consent is not required.

Legal basis: Art. 6(1)(f) GDPR — legitimate interest in understanding the use of my own website, using data that is not personal to you.

5. Cookies and local storage

This website sets no tracking cookies. A single session cookie is created only if you sign in to the administration area, and it is strictly necessary for that login.

Your preference for light or dark mode is stored locally in your browser and is never transmitted to the server.
